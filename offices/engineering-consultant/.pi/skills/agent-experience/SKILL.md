# Review and improve agent task experience

Run representative tasks through the same tools and instructions a real agent sees. Check capability discovery, argument clarity, state visibility, result usefulness, error recovery, interruption and continuation. Inspect unnecessary calls, invalid arguments, context churn, repeated discovery and user rescues. Keep safety checks whose extra call prevents a costly error. Prefer stable responsibilities over convenience-driven hot swaps. Measure task success and interventions with call/time/token data as supporting evidence, not goals alone. Revise schemas, workflow and documentation together; rerun failed cases and a regression scenario. Do not infer agent quality from tool aesthetics alone.

Follow the shared practice in AGENTS.md; use this method only when it helps the task.
