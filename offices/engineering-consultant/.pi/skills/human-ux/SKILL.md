# Review and improve human task experience

Choose representative user goals and realistic starting knowledge. Walk the flow through the actual interface. Record friction at discovery, input, feedback, state transitions, completion and recovery. Include interruptions and errors, not just the happy path. Check accessibility where the interface exposes it. Remove unnecessary remembering, re-entry, hidden state and choices the system can safely make. Revise when commissioned and repeat the task. Distinguish your walkthrough from evidence gathered from real users. Avoid cosmetic redesign that leaves the task friction unchanged. Explain trade-offs in human effort and agent/system coherence.

Follow the shared practice in AGENTS.md; use this method only when it helps the task.
