# Design direction — decision aid

Use this only for material visual decisions; do not run a fixed checklist for minor repairs.

1. **Subject and purpose.** What is the product, who will use it, and what is the first action or impression? Read real content and constraints before choosing style.
2. **Character.** Choose a few traits suited to the brief (e.g., quiet, playful, precise, intimate). Contrast at least one plausible alternative. Don't reuse the same palette, fonts or card layout across unrelated products.
3. **System.** Give a practical starting set of type roles, colors and contrast intent, spacing rhythm, layout rules, interaction feedback and key component states. Reuse an existing design system where it fits.
4. **Proof.** Show the design in a meaningful screen with realistic content. Where useful, make a second variation and state what changed.
5. **Limits.** A visual concept is a design proposal, not user validation. Mark unknown content, simulated behavior and unchecked accessibility plainly.

Avoid decorative structures that imply information not present: fake metrics, unexplained status colors, gratuitous number labels, repetitive cards or motion without a job. These patterns are not forbidden; they need a reason that fits the content. Favor a readable first impression and a usable complete flow.
