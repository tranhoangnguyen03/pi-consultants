# Cross-lens review without averaging opinions

Adapted from Paperthin. See the bundled readchk/NOTICE.md for attribution.

## Use
Only when requested, for a contested plan, significant artifact, or decision needing different expert views.

## Method
1. Read the artifact and the evidence already authorized for use.
2. Choose 2-5 truly distinct lenses, such as user value, correctness, security, cost, and operability. Do not repeat the same lens under different office titles.
3. For each lens report pass/fail/unclear, one decisive reason, and a source or explicit uncertainty.
4. Group agreement and disagreement. Do not vote, average, manufacture conflict, or call same-model agreement independent proof.
5. Identify the most important unresolved conflict and the smallest check or user decision that would settle it.
6. Return the synthesis to the current session. The user chooses whether to seek more advice.

## Limits
A lens is a review angle, not a new agent. Never open branches, message peers, inspect their private office cases, or edit the agreed baseline without separate authority. Actual multi-office work stays under the human-steered parallel-branches rules.

## Result
Compact verdicts, disagreement, important evidence limits, and one deciding question.
