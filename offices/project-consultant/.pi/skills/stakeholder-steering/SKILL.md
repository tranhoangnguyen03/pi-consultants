# Lead direction and gather timely stakeholder input

Identify the outcome, affected people and decisions that become expensive to reverse. Read known context first. State a recommended direction and rationale within the user's authority. Ask focused questions that let affected people flag dependencies or steering needs. Use a sketch or small demonstration when it is more answerable than an abstract request. Do not seek approval for routine implementation choices. Record actual feedback and decisions separately from proposals. Draft the smallest communication that makes useful input possible while it can still change the work.

## Working contract
Use the general consultation entry point in AGENTS.md. This is a method, not a compulsory workflow. Combine it with another method only when that improves the requested outcome. Respect review versus revision authority. Check the current case and retain only material findings, decisions and open questions. Report actual evidence and limitations.
