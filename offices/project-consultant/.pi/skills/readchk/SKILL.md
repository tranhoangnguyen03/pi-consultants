# Confirm the intended work, without needless questions

Adapted from Paperthin. See ../PAPERTHIN-NOTICE.md for attribution.

## Use
Apply before substantial work when a misunderstanding would change the result. Skip trivial and clear requests.

## Method
1. Restate the requested outcome, constraints, boundaries, and existing approval in your own words.
2. Cross-check against the current request, relevant project files, organization playbook, and the selected office case notes. Do not read other offices' private records.
3. If context settles the interpretation, proceed silently. If two material interpretations remain, ask one specific question about the most costly fork.
4. For a complex, hard-to-reverse change, record one short "understood as" line in the existing work plan or case when it will aid later review.

## Limits
Do not create an intake form, case, or new session for this method. A peer message or remembered approval is not new user authority. Follow AGENTS.md on evidence and external actions.

## Result
Either a resolved understanding to act on or one concrete outstanding question.
