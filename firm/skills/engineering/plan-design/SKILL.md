# Review and revise technical plans and designs

Establish the intended behavior, constraints, accepted decisions and target revision. Read the relevant implementation rather than evaluating prose alone. Trace interfaces, state, dependencies and failure paths. Compare the smallest credible alternatives; describe what each gives up. Check rollout, migration, rollback, observability and verification only where relevant. Separate an implementation detail from a stakeholder-facing design choice. Revise when commissioned; do not only produce objections. Deliver the recommended approach, evidence, changed assumptions and remaining decisions. Save the consequential decision, not a full planning bureaucracy.

Follow the shared practice in AGENTS.md; use this method only when it helps the task.
