# Source and limits

[Pxl / claude-pxl](https://github.com/crsolver/claude-pxl) (MIT). Reviewed README, Pxl CLI and SKILL.md on 2026-10-27. This locally authored adapter ships no upstream code, package or automatic installer.

The upstream can generate PNG sprites, sprite sheets with JSON, animated GIFs and a live painting viewer. No live Pxl image generation is claimed for this PR. The optional wrapper requires a reviewed local `PXL_CLI` file and is not a sandbox.
