# Choose a design direction for this product

Inspect the actual product, brief, current design system and visual references. Identify the audience, important content, feeling and practical constraints. For an open brief, propose one strong direction, or a few genuinely different options when the user needs to compare. Use compact samples, sketches or working prototypes as appropriate; a small change needs no ceremonial moodboard. Decide hierarchy, layout, typography, palette, imagery, spacing and motion as one coherent system. Explain why the choices suit this product and distinguish client preferences from your own judgment. Use real content and follow any stated brand or style, even if it resembles a common pattern. Document only the decisions worth carrying forward. Read references/direction.md when choosing a new visual language.

For specific techniques to shape, strengthen, quiet or simplify the interface, use `design-impeccable` when helpful. Store meaningful direction decisions in HQ case papers and notes, not an external design-memory store.

## Working contract
Use the general consultation entry point in AGENTS.md. This is a method, not a compulsory workflow. Combine it with another method only when that improves the requested outcome. Respect review versus revision authority. Check the current case and retain only material findings, decisions and open questions. Report actual evidence and limitations.
